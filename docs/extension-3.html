Mechanisms: The Four-Bar Lift

Optional, for early finishers. Robot arms often use a four-bar linkage, which keeps a claw level as it lifts. In this extension you model one with plain bars in Onshape, make it move, and see why it works.

Mates that move

A revolute mate spins around one axis, like your skateboard wheels in Week 7. Add limits so the model stops where a real arm would stop.

The parallel four-bar

Four links joined at four pivots: the tower, two arms, and the top link. When the two arms are equal and the top link matches the tower, the top link stays at the same angle the whole way up. That’s why robot lifts use it to keep a claw level.

Goal: four bars

Model the links

Model a tower and a top link of the same length, and two arms of the same length. Put a hole at each end.

✅ Check it: opposite links match in length.

Goal: it moves

Mate the pivots

In an Assembly, fix the tower. Add revolute mates at all four holes.

✅ Check it: drag an arm. The whole linkage moves.

Goal: proof it stays level

Limit, animate, check

Add limits, then animate. Watch the top link and look for collisions.

✅ Check it: the top link never tilts, and no parts overlap.
