📚 Onshape lessons

Onshape Intro to CAD — Unit 3: Onshape Power Tools. Use lessons 3.1–3.2. Each lesson has a slide deck and a student guide.

  • 3.1 How the Pros Do It. Learn design intent. Build 3D parts from 2D sketches. Set your workspace units.
  • 3.2 One Brick to Rule Them All. Build a brick with a configuration table, so one part makes many brick sizes.

Lessons 3.3 and 3.4 are optional. Try them if you finish early.

Block 1 — set the class connection standard

  • Agree on the standard. As a class, choose the peg diameter, the peg spacing, and the base height. Write them in your notebook.
  • Model the connector. In Onshape, model one peg and one socket block that match the standard. Work in millimeters.
  • Add a configuration. Make a configuration table for the socket with three clearances: 0.2 mm, 0.3 mm, and 0.4 mm. Socket = peg + clearance.
  • Submit. Export your connector. Your teacher prints one class set of test coupons on Wednesday.

Block 2 — test the fit and lock it in

  • Test each socket. Push the peg into each socket. Which one is snug without forcing?
  • Record it. Write the result for each clearance in your notebook: too tight, just right, or too loose.
  • Lock it in. The class picks one clearance. That number is now part of the standard. Every section in the park uses it.

Why it matters: This is the same clearance rule from Weeks 8 and 9. Now it decides whether twelve teams’ parts fit together.
